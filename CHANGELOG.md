# Changelog

## 0.8.0 – 2026-03-21

- Reduced steps and and date font size for smaller devices.

## 0.7.0 – 2026-03-20

- Changed time font size from 42 to 44.

## 0.6.0 – 2026-03-20

- Added support for Pebble Round 2.

## 0.5.0 – 2026-03-20

- Changed fonts to Inter.

## 0.4.0 – 2026-03-20

- Changed the time font from LECO to Bitham.
- Increased font size for steps and date.

## 0.3.0 – 2026-01-16

- Added support for all current devices.
- Improved visibility of the low battery indicator.

## 0.2.0 – 2026-01-16

- Added smart date formatting: Displays `MM-DD` when 12h clock is selected, and `DD-MM` for 24h clock.

## 0.1.0 – 2026-01-16

- First release.
